# 图表选型指南

## 图表类型选择
| 数据关系   | 推荐图表   |
|-----------|-----------|
| 趋势/时间  | 折线图     |
| 比较/排名  | 柱状图     |
| 占比       | 饼图/环形图 |
| 分布       | 直方图/箱线图|
| 相关性     | 散点图     |
| 多维度比较 | 雷达图/热力图|

## 通用规则
- 坐标轴标签清晰可读
- 颜色不超过 5 种主色
- 添加数据标签或图例
- 标题描述图表内容
